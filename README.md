# Neon Dash

A neon rhythm platformer built with vanilla JavaScript and HTML5 Canvas. No frameworks or build step — just open `index.html`.

## Play

```bash
# Any static server works, e.g.:
python3 -m http.server 8000
# then open http://localhost:8000
```

Or simply open `index.html` directly in a browser.

## Controls

- **Space / Up Arrow / Click or Tap** — jump / fly
- **P / On-screen pause button** — pause
- **R** — retry
- **M** — mute
- **Esc** — back to menu
- In the level editor: **Click or Tap** to place, use the **Erase** tool (or right-click) to erase, **A/D** or the mouse wheel to pan, and **two-finger drag** to pan on touch screens. Use **Ctrl+Z** to undo and **Enter** to test.
- Use the editor's **Export** button to download the current level as a `.ndcl` file, or **Import** to load one. Imported files are validated and open as an unsaved editor level until you choose **Save**.
- On touch screens, swipe the level list to browse saved custom levels.

## Features

- Cube and ship game modes
- Jump pads, jump orbs, and portals
- Spike and block obstacles with forgiving hitboxes
- Multiple speed zones (slow / normal / fast / very fast)
- Practice mode with checkpoints
- Level editor with save/load, undo, play-testing, and `.ndcl` custom-level import/export; saved custom levels are available from **Play**
- Player settings for username, icon shape, and preset or custom color
- Supabase account sign-in with email/password and cloud saves for progress, profile, and saved custom levels; Google sign-in is marked as coming soon
- Newsletter signup for Neon Dash Updates via a Brevo-hosted, double-opt-in form
- Attempt counter, death counter, and progress tracking
- Particle effects, screen shake, and player trail

## Files

- `index.html` — entry point
- `game.js` — all game logic
- `styles.css` — canvas styling
- `supabase-config.js` — public Supabase project URL and publishable key
- `supabase/schema.sql` — per-user cloud-save table and row-level security
- `updates.html` — responsive Neon Dash Updates signup page with the embedded Brevo form
- `actions.json` — scripted input sequence (for automated testing/playback)
