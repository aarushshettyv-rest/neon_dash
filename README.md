# Neon Dash

A neon rhythm platformer built with vanilla JavaScript and HTML5 Canvas. No frameworks or build step — just open `index.html`. Playable as a website, installable PWA, and as a Discord Activity with Rich Presence.

## Play

```bash
# Any static server works, e.g.:
python3 -m http.server 8000
# then open http://localhost:8000
```

Or simply open `index.html` directly in a browser.

### Windows desktop app

A native Windows build (WebView2, no Electron) lives in `desktop/`:

```bat
desktop\build.bat
:: produces desktop\dist\NeonDash.exe — portable, game files bundled inside
```

The desktop app shows live Discord Rich Presence (level, attempt, progress) via Discord's local IPC — no Activity launch needed. Requires the .NET Framework 4.x `csc.exe` (included with Windows) and the WebView2 runtime (preinstalled on Windows 10/11).

## Controls

- **Space / Up Arrow / Click or Tap** — jump / fly
- **P / On-screen pause button** — pause
- **R** — retry
- During a Momentum portal effect, hold **A / Left Arrow** to brake or **D / Right Arrow** to boost; touch players can hold the on-screen controls.
- In Practice mode, press **C** while paused to set a checkpoint where you are, or choose **Set Checkpoint & Retry** after a death. Press **R** to restart from the latest checkpoint.
- **M** — mute
- **Esc** — back to menu
- **⚙ cogwheel (top-left corner)** — opens Settings from any menu screen
- In the level editor: **Click or Tap** to place, use the **Erase** tool (or right-click) to erase, **A/D** or the mouse wheel to pan, and **two-finger drag** to pan on touch screens. Use **Ctrl+Z** to undo and **Enter** to test.
- Use the editor's **Export** button to download the current level as a `.ndcl` file, or **Import** to load one. Imported files are validated and open as an unsaved editor level until you choose **Save**.
- On touch screens, swipe the level list to browse saved custom levels.

## Features

- Cube and ship game modes
- Jump pads, jump orbs, and portals
- Spike and block obstacles with forgiving hitboxes
- Multiple speed zones (slow / normal / fast / very fast)
- Practice mode with checkpoints
- Level editor with save/load, undo, play-testing, `.ndcl` custom-level import/export, and portals for size, bounce, gravity, double-jump, slow-time, and momentum; saved custom levels are available from **Play**
- Player settings for username, icon shape, preset or custom color, ghost visibility, and separate music/SFX volume adjustable in 25% steps
- Supabase account sign-in with email/password and Discord OAuth, plus cloud saves for progress, profile, and saved custom levels; Google sign-in is marked as coming soon
- Discord Activity mode: Rich Presence (level, attempt, progress) and an invite dialog when launched inside Discord; gracefully disabled on the open web
- Installable PWA with offline play for built-in levels (manifest, service worker, icons); an **Install app** button in Settings triggers the browser install prompt
- Community menu with an embedded Discord server widget for joining the community
- Account button in the main menu for sign-in/cloud saves; Settings behind a top-left cogwheel with Updates/Privacy/Terms links
- Newsletter signup for Neon Dash Updates.
- Attempt counter, death counter, and progress tracking
- Fixed 60 Hz physics updates, independent of display refresh rate
- Automatic local best-run ghost replays with a visible path line in practice mode and editor tests
- Particle effects, screen shake, and player trail

## Files

- `index.html` — entry point
- `game.js` — all game logic
- `styles.css` — canvas styling and overlays (auth modal, Discord server widget)
- `supabase-config.js` — public Supabase project URL and publishable key
- `supabase/schema.sql` — per-user cloud-save table and row-level security
- `updates.html` — responsive Neon Dash Updates signup page with the embedded Brevo form
- `actions.json` — scripted input sequence (for automated testing/playback)
- `manifest.json`, `sw.js`, `icon*.png`, `icon.svg` — PWA installability and icons
- `discord-sdk.mjs` — vendored `@discord/embedded-app-sdk` v2.5.0 bundle (used only inside Discord Activities)
- `terms.html`, `privacy.html` — legal pages required for the Discord app listing
- `cover-1920x1080.png` — Discord activity cover image asset
- `desktop/NeonDash.cs`, `desktop/build.bat` — native Windows app (WebView2 + Discord IPC rich presence); `desktop/dist/` is the build output (gitignored)
- `neon-dash-bot/` — Discord bot project (slash commands etc.), separate Node.js app with its own `.env`
